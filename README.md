# Ticket Management System

A command-line application developed in Java for managing support tickets using dynamic data structures.

## Project Status

🚧 **In development**

This project is currently under development as part of a Data Structures course.

## Current Features

- Creation of tickets with unique sequential IDs.
- Automatic registration of creation dates.
- Registration of ticket resolution dates.
- Storage of resolved tickets using a singly linked list.
- Search for resolved tickets by ID.

## Planned Features

- Priority queue for pending tickets.
- User command-line interface (CLI).
- Administrator command-line interface (CLI).
- Ticket creation and tracking.
- Resolution of pending tickets.

## Data Structures

The project is designed to implement dynamic data structures without relying on Java's built-in collection implementations for the main ticket management logic.

Currently implemented:

- Singly Linked List

Planned:

- Priority Queue
